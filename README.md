# 词屿 · Render 部署版

四模块单词学习 + 后台分配学习账号 + 多学习方向独立词库 + 个人进度跨设备同步。管理员可用 CSV / JSON 导入、发布各模块的词库。使用 Node.js 和 PostgreSQL，不需要安装 Cloudflare 工具。

## 从 GitHub 部署（使用外部 PostgreSQL）

本项目只在 Render 创建网站服务，**不创建 Render 数据库**。你可以自行选择其他平台的 PostgreSQL。

1. 解压项目，把**文件夹里面的内容**上传到 GitHub 仓库根目录。根目录应直接看到 `render.yaml`、`package.json`、`package-lock.json`，不要只上传 ZIP。
2. 登录 Render，选择 **New → Blueprint**，连接此 GitHub 仓库。
3. Render 读取 `render.yaml`，只创建一个 Free Web Service。
4. 按提示填写 `DATABASE_URL`（外部 PostgreSQL 连接串）和 `ADMIN_PASSWORD`（你设置的后台密码）。
5. 确认创建，等待部署成功。数据库表会在服务启动时自动初始化。
6. 地址后加 `/admin.html`，使用 `ADMIN_PASSWORD` 登录后台，创建学习账号并分配学习方向；学生在网站首页使用分配的账号登录。

### 需要配置的环境变量

| 变量 | 是否必填 | 填写内容 |
| --- | --- | --- |
| `DATABASE_URL` | 是 | 数据库平台提供的 PostgreSQL 连接串，包含用户名、密码、主机、端口和数据库名 |
| `ADMIN_PASSWORD` | 是 | 自行设置的长随机密码，用于登录词库管理后台 |
| `PUBLIC_ORIGIN` | 否 | 使用自定义域名时填写，例如 `https://words.example.com`；默认 Render 域名无需填写 |
| `PORT` | 否 | Render 自动提供；本地默认 3000 |

连接串示意：`postgresql://用户名:密码@数据库地址:5432/数据库名`。优先复制提供商给出的完整连接串，保留提供商要求的 SSL/TLS 查询参数；若手工组装，密码中的 `@`、`:`、`/` 等特殊字符需 URL 编码。不要把真实连接串或密码上传到 GitHub，填写在 Render 的 Environment 中。

数据库地址需要能从 Render 连接，不能填写你电脑的 `localhost`。数据库账号需要能创建本项目的表和索引。首次部署建议使用专用数据库；自动建表 SQL 位于 `migrations/`，启动时按文件名顺序执行，也可按顺序在数据库平台手动执行。连接失败时服务停止启动，不会改为临时文件存储。

Render 免费 Web Service 闲置 15 分钟后会休眠，首次访问需要等待启动。词库、账号和个人学习进度保存在外部 PostgreSQL，Render 重启不会删除这些数据；外部平台自身的免费额度、休眠和保留期限由该平台决定。浏览器另存当前账号、当前学习方向的本机副本，网络恢复后继续同步。

如果此前已经创建了 Render 数据库，本次配置变更不会自动迁移其数据；请先备份、迁移或逐模块导出词库，再修改 `DATABASE_URL`。不要在确认迁移成功前删除旧数据库。

官方说明：[Render 免费限制](https://render.com/docs/free)、[GitHub Web Service 部署](https://render.com/docs/web-services)、[Blueprint 配置](https://render.com/docs/blueprint-spec)。

## 手动创建 Web Service

如果不使用 Blueprint：准备好外部 PostgreSQL 连接串，再创建 Web Service 并连接 GitHub：

| 设置 | 值 |
| --- | --- |
| Language | Node |
| Build Command | `npm ci --omit=dev` |
| Start Command | `npm start` |
| Health Check Path | `/healthz` |
| Instance Type | Free（或自行选择） |
| Root Directory | 文件在仓库根目录则留空 |

添加环境变量：

- `DATABASE_URL`：外部数据库提供商的连接串，保留其要求的 TLS 参数。
- `ADMIN_PASSWORD`：你设置的管理员密码。
- `NODE_VERSION`：`22`。
- `PUBLIC_ORIGIN`：仅在使用自定义域名时填网站完整来源，例如 `https://words.example.com`。默认自动使用 Render 分配的网址。

数据库凭据、密码只填 Render Environment，不上传 `.env`。启动时数据库不可用会直接报错停止，不会改用可能丢数据的临时存储。

## 功能

1. 单词认知：英文、音标和朗读；“英译英”和“中文翻译”始终并列显示，分别展开或收起，可任选顺序；中文区域含英文例句。
2. 英译中选择：中文释义选项、即时校验。
3. 中译英拼写：中文提示、输入英文；答错展示答案、音标、朗读、英文释义和例句。答对也停留在反馈页，手动点击“下一步”，不受自动继续开关影响。
4. 听音拼写：点击播放发音，填写英文，不提前显示答案。

默认提供以下五套只读词库，按 ECDICT 标签全量收录；六级包含四级基础并去重。它们是开源备考参考词表，不能视为考试机构官方完整考纲。

| 默认学习方向 | 词条数 |
| --- | ---: |
| 高中 · 通用高考 | 3,677 |
| 四级 | 3,849 |
| 六级（含四级基础） | 5,805 |
| 雅思 | 5,040 |
| 托福 | 6,974 |

默认词库中的全部词条可用于四个模块，各模块独立保存未完成轮次；自定义方向可给四个模块分别导入不同的词。默认内容由服务端禁止覆盖，管理员要调整时须复制为自定义方向。`北师大版高中 · 教材词库（待导入）` 作为独立自定义方向预留，不把通用高考词表误标为教材同步内容。

词库包含中文释义、来源已有的音标和英文释义，以及自动匹配的 Tatoeba 双语例句。不是所有词都有音标、英文释义或例句，缺失字段显示“待补充”，不会用占位句冒充真实例句；朗读仍可使用设备语音。具体覆盖数量、原作者归属与许可证见网站 `/data-sources.html`。保留 SVG 插图、错题重试、复习调度和学习备份。词库列表分页展示，接口压缩传输，适合数千词的默认库。纯静态预览仍使用原 18 个示例词。


四个模块各自保存未完成轮次，普通切换无需确认，刷新、备份与恢复也会保留各模块的答题位置。旧版的单份轮次自动迁入所属模块。从词库打开单个词的专项练习会重新开始该模块的轮次，此时仍会确认；其他模块不受影响。

## 后台分配账号

1. 打开 `/admin.html`，使用 Render 中的 `ADMIN_PASSWORD` 登录。
2. 在“账号管理”中填写账号名、姓名或昵称、至少 8 位密码，勾选内置默认或自定义学习方向（可多选），点击“创建账号”。账号名为 3–40 位英文、数字、点、下划线或短横线，不区分大小写。
3. 将账号和所设密码交给使用者。学生没有自行注册入口，登录后只能进入已分配的方向。
4. 点击账号旁的“编辑 / 重置密码”可调整方向、昵称和启用状态。密码留空表示不改，填写新密码表示重置。重置密码或停用账号会使原登录状态失效，已保存的进度仍保留。

没有预设学生账号，也不会自动发送账号信息。后台不能查看原密码，只能重置。学习账号密码采用带独立盐值的 scrypt 哈希存储；登录凭据为 HttpOnly、SameSite Cookie，HTTPS 下启用 Secure，数据库只保存会话令牌的摘要。管理员密码仍只放在 Render 环境变量中。

### 个人进度与旧版升级

- 每人的进度按“账号 + 学习方向”分开，包括各模块未完成轮次、错词、收藏、偏好及最近 120 轮记录。高中与四六级等方向分别计进度；不同账号互不覆盖。
- 答题后先保存本机副本，再提交云端。看到“账号已同步”后可换设备继续；离线修改在页面打开且网络恢复后重试。
- 两台设备同时修改会显示冲突提示，暂停上传。可先“导出本机备份”，再明确选择“使用云端进度”或“使用本机进度”。这是选择一份完整记录，不自动合并两边答案。选择前还会在本机保留一份恢复副本。
- 浏览器中的本机记录按账号、方向分别保存。共用设备换账号时，旧标签页无法把旧账号记录写入新账号。退出登录后仍保留本机缓存，便于原账号回来恢复未同步记录；不要与不信任的人共用浏览器系统账户。
- 现有部署直接更新代码即可，仍用原 `DATABASE_URL` 和 `ADMIN_PASSWORD`。启动按顺序迁移表结构并安装内置词库。`003_builtin_catalogs.sql` 增加方向类型，随后安装逻辑将原五个方向中已导入的词库或已有进度归档为“原有词库 · …”自定义方向，同时复制原账号授权和云端进度；旧方向 ID 变为受保护默认方向。重复启动不覆盖自定义内容。内置词条随仓库提供，不需要启动时从外网下载。
- 原匿名学习记录不会自动归给任意登录者。确认记录属于本人后，进入对应的高中或“原有词库 · 高中…”方向的“设置与备份 → 导入旧版进度”；也可导入之前导出的 JSON 备份。导入将替换该账号的高中进度，其他方向不受影响。

新增账号功能需要 Node.js 服务和 PostgreSQL；直接静态预览仍可体验示例四模块，但不提供账号管理和跨设备同步。

### 旧版 iOS 与连接失败排查

前端请求使用 `AbortController` 实现超时，避免依赖 iOS 15 缺少的 `AbortSignal.timeout`。学习记录复制、UUID 和属性检查也不依赖旧版系统缺少的新接口；不支持原生 dialog 的浏览器使用带焦点管理的兼容弹窗。词库首次读取每次最多等待 30 秒，遇到超时、网络或临时服务错误会自动重试一次。

持续失败时页面会区分网络、超时、HTTP 状态和数据格式问题，并保持原有学习记录。手机只连接本站接口，由 Render 连接 PostgreSQL，不需要手机直接连接 Neon。更新部署后先重新加载页面或在 Safari 打开；不要为了排查而清除网站数据，否则会删除未同步的本机进度。若仍然报错，请记录完整提示；可访问 `/api/status` 查看版本和 `/healthz` 检查数据库连接。旧 `/api/catalog` 已改为要求账号鉴权，未登录时返回 401 属于正常行为。

兼容回归通过模拟禁用旧版 iOS 缺失的接口来验证，不能替代真实设备和实际网络测试。

## 导入词库

进入 `/admin.html → 词库管理`：

1. 在“新建自定义学习方向”填写名称，选择“空白方向，稍后导入”，或选一套词库作为复制来源。也可选中默认库后点击“复制为自定义方向”。
2. 点击“创建自定义方向”后，页面自动选中新方向，再选择要维护的模块，上传 CSV（UTF-8）或 JSON。
3. 预览确认后“发布当前模块”。只替换该自定义方向的当前模块，其他模块和默认库不变。复制不会复制学习进度或账号授权。
4. 回到“账号管理”，勾选新方向并保存，学生才能看到这个入口。

必填列：`word`（或 `id`）、`meaning`。建议同时提供 `ipa`、`definition`、`sentence`、`translation`。例句如有填写，须包含目标单词；缩写与词组也可导入。模板在 `templates/`，每次 1–20000 词，文件及请求最大 8 MB，后台预览最多展示前 60 条，可导出全部内容。发布检查版本，防止覆盖另一位管理员的更新。管理员密码仅保存在当前管理页面内存中。

导出或复制内置词库时保留 `source`、`attribution` 字段；这些字段会随自定义导入和导出保留。再次分发 ECDICT 与例句数据时也应附带 `public/licenses/` 中的许可与来源说明。

### 配置单词录音

可选列 `audioUrl` 指定当前单词的录音：填写可直接播放的 HTTPS 音频地址，或将单词音频放进 `public/audio/` 随仓库部署，再填写 `/audio/explore.mp3` 这样的本站路径。支持 MP3、M4A、WAV、OGG（实际解码支持取决于浏览器，优先使用 MP3）。后台导入预览会显示录音地址，四个学习模块都会优先播放该词配置的录音。本站音频支持分段请求，适用于手机播放器。

留空时使用设备合成语音，优先选择英式英语（`en-GB`），没有时选择其他可用英语语音，语速为 0.88。该声音不等同于北师大教材原声，也可能因设备而不同。页面区分“词库录音”和“设备合成语音”；已配置录音但加载失败时会提示错误，不会悄悄换成合成语音。

本仓库尚未包含北师大高中教材录音。要对齐教材发音，需要与具体册次、版本相符的原始音频；每个地址应对应一个英文单词，整本或整单元录音需先整理成单词片段再配置。

## 本地开发与测试

需要 Node.js 22+，以及一个 PostgreSQL 数据库。

```sh
npm ci
# 参考 .env.example 创建 .env，填入实际连接信息。
node --env-file=.env server/index.js
```

默认 http://localhost:3000 。执行 `npm test` 运行单元和数据库适配集成测试（测试使用内存 PostgreSQL 模拟器，不访问生产数据库）。

`migrations/` 包含 PostgreSQL 建表 SQL，启动会幂等执行；不是 Cloudflare D1 的 SQL。账号授权和进度隔离由服务端执行，交互采用参数绑定与版本冲突检查。测试覆盖账号分配、课程访问权限、密码重置、停用、跨设备恢复、并发冲突、离线重试，以及原四模块学习行为。

### 重建内置词库

应用部署直接使用已提交的 `data/builtin/lexicon.json` 和 `manifest.json`。开发时可重建：

```sh
python3 scripts/build-builtin-catalogs.py /path/to/ecdict.csv /path/to/cmn-eng.zip
```

ECDICT 固定版本为 `bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`，脚本核验完整 Git blob 校验值，拒绝截断文件。词条按频率排序，释义取前两段；例句选自 ManyThings 的 2026-02-13 英汉句对，并逐条保留 Tatoeba 原作者与句子编号。源文件 SHA-256 和覆盖统计记录在 manifest 中。词库来源：[ECDICT](https://github.com/skywind3000/ECDICT)、[ManyThings/Tatoeba](https://www.manythings.org/anki/)。

升级到此版仍使用原 Render / Neon 环境变量；`/api/status` 中 `version: 3`、`builtinCatalogs: true` 表示已运行此版代码。本地验证或 GitHub 推送成功不代表 Render 已部署，需以实际站点状态为准。
